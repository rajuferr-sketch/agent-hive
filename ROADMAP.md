# AgentHive Roadmap

This file tracks the suggested improvements for turning AgentHive into an autonomous multi-agent development platform.

## Implemented (high-level)
- Repository intelligence: import GitHub repos and analyze file tree/languages/entry points.
- Token manager: basic accounting and budget checks.
- Model router: initial provider routing hook.
- Ingestion, SSRF hardening, secret scan, host provider, quiet logs, etc.

## Planned (from suggestions)
See the full numbered list in the project discussion; items include dynamic orchestration, repository intelligence engine, code modification engine, isolated execution environments, testing/quality gate, model router, token manager, semantic memory, agent communication, security, web dashboard, GitHub integration, scalability, learning/optimization and compatibility.

Status: in progress. Contributions welcome.
